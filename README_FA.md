# راهنمای فارسی Beauty Try-On Benchmark

این بسته **کل پروژهٔ فاز صفر** است: انتقال مدل و رنگ مو با HairFastGAN، رنگ مو با سگمنتیشن و LAB، دریافت عکس و مدجع، نمایش موقت، سنجش زمان/VRAM، بنچمارک ۳۰ عکس و تست‌ها. مدل HairFastGAN متعلق به سازندگان اصلی است؛ سهم این پروژه پایپ‌لاین اجرا، تست، حریم خصوصی و ارزیابی است.

محصول نهایی سالن، اپ موبایل، پنل کاربری و دیتابیس در این فاز ساخته نشده‌اند. StableHair v2 و انتقال/پریست آرایش هنوز پیاده نشده‌اند.

**نسخهٔ Colab تست‌شده:** [Beauty Try-On Phase-0 Professional T4](https://colab.research.google.com/drive/1B8Mj0FYPIQ4B9N0EQ2L5t2udpY1YKp4t?usp=sharing)


## از کجا شروع کنم؟

۱. فایل ZIP را باز کن. داخل پوشهٔ `notebooks` فایل **Beauty_TryOn_Phase0_T4.ipynb** را پیدا کن.

۲. در Colab از **File → Upload notebook** همین فایل را باز کن. لازم نیست سورس‌ها را دستی کپی کنی یا فایل ZIP پروژه را به Runtime آپلود کنی؛ کدهای لازم داخل سلول‌های نوت‌بوک هستند.

۳. از **Runtime → Change runtime type** گزینهٔ GPU و سپس T4 را انتخاب کن. سپس **Run all** را بزن و اجازه بده سلول‌ها به‌ترتیب تمام شوند.

| سلول | کار |
|---|---|
| ۱ | بررسی GPU و مسیرها |
| ۲ تا ۳ | نوشتن کد تنظیمات و نصب |
| ۴ | نصب محیط مستقل و کتابخانه‌ها |
| ۵ تا ۶ | کد دریافت و دانلود وزن‌ها |
| ۷ تا ۱۵ | فایل‌های خوانای موتور، دریافت عکس و تست‌ها |
| ۱۶ | ساخت worker و بررسی سلامت CUDA و تست‌های اولیه |
| ۱۷ و ۱۸ | دموی عمومی انتقال مو و رنگ مو |
| ۱۹ | گزارش موفقیت همین اجرای دمو |
| **۲۰** | **انتخاب عکس فرد، انتخاب مرجع مو و نتیجه؛ پیش‌فرض روشن** |
| ۲۱ | تست رنگ از مرجع؛ پیش‌فرض خاموش |
| ۲۲ | بنچمارک ZIP شامل ۳۰ عکس؛ پیش‌فرض خاموش |
| ۲۳ | بستن پردازش مدل |

۴. در سلول ۲۰ ابتدا عکس فرد و سپس عکس مرجع را انتخاب کن. در هر عکس فقط یک چهره باشد. نتیجه از چپ به راست: عکس اصلی، چهرهٔ هم‌تراز، مرجع و خروجی. HairFastGAN در این نسخه هم فرم و هم رنگ مو را از مرجع می‌گیرد.

۵. برای عکس‌های بعدی **فقط سلول ۲۰** را دوباره اجرا کن؛ نصب و دانلودها را تکرار نکن. اگر زمان انتخاب فایل تمام شد، باز هم فقط ۲۰ را اجرا کن. برای رنگ از مرجع، پرچم `RUN_COLOR` در ۲۱ را True کن و همان سلول را اجرا کن.

## چه فایل عکسی پذیرفته می‌شود؟

JPEG/PNG/WEBP ثابت، حداکثر ۲۵ MiB و ۱۶ میلیون پیکسل، یک چهرهٔ واضح. عکس با EXIF جهت‌دهی می‌شود، متادیتا حذف می‌شود و ضلع بلند در صورت نیاز به حداکثر ۱۶۰۰ پیکسل کاهش می‌یابد. خروجی انتقال مو crop هم‌تراز ۱۰۲۴×۱۰۲۴ است و بازسازی قاب اصلی موبایل انجام نمی‌شود.

## اگر فایل‌های نصب موجود نبودند

Colab ممکن است محیط اجرای تازه‌ای بدهد. باقی‌ماندن تصاویر و جدول‌های قبلی در نوت‌بوک به معنای وجود وزن‌ها در Runtime تازه نیست. در چنین شرایطی مراحل آماده‌سازی را در همین محیط دوباره اجرا کن. هنگام اجرای نصب و دانلود، Runtime را عوض یا حذف نکن. کدهای این نسخه اصلاح PNG و CLIP را از ابتدا دارند؛ سلول‌های وصلهٔ نسخه‌های قبلی لازم نیستند.

## بنچمارک واقعی

با ساختار [examples/manifest.json](examples/manifest.json)، یک ZIP با manifest.json در ریشه و عکس‌ها بساز؛ تصاویر لازم نیست نام اشخاص داشته باشند. هر گروه A، B و C دقیقاً ۱۰ مورد دارد. برای اجرا `RUN_BATCH` در سلول ۲۲ را True کن. ZIP در حافظه خوانده می‌شود و استخراج نمی‌شود. برای هر نتیجهٔ موفق، سه نمرهٔ **Identity، Hairline و Reference** بین ۱ تا ۵ را وارد کن؛ مثلاً `4 4 5`. سپس نمره و سنجهٔ بی‌نام به CSV/JSON می‌روند.

گیت HairFastGAN: حداقل ۲۱ خروجی با هر سه نمره ≥۴، و حداقل ۲۱ خروجی که هم این کیفیت و هم inference کمتر از ۸ ثانیه دارند. آستانهٔ ۴ تعریف عملیاتی پیشنهادی است و باید پیش از ارزیابی توافق شود. خطاها در مخرج ۳۰ می‌مانند. موتور رنگ با حد مستقل ۰٫۵ ثانیه بررسی می‌شود؛ نتایج دو موتور جمع نمی‌شوند.

## وضعیت واقعی پروژه

در اجرای ثبت‌شدهٔ Colab در **۵ اکتبر ۲۰۲۶** روی **Tesla T4**، تست CUDA موفق شد، ۱۲ تست اصلی، ۹ تست Runtime و تست شش اپراتور pinned همگی با موفقیت تمام شدند. دموی عمومی HairFastGAN زمان خالص **۲٫۰۶۱ ثانیه**، زمان کامل پایپ‌لاین **۱۰٫۲۴۲ ثانیه** و Peak VRAM برابر **۶۹۰۵٫۴ MiB** ثبت کرد. موتور رنگ مو نیز زمان خالص **۰٫۱۴۲ ثانیه**، پایپ‌لاین **۰٫۱۵۱ ثانیه** و Peak VRAM برابر **۳۰۵٫۲ MiB** ثبت کرد.

این نتایج **دموی تک‌نمونه در نسخهٔ حرفه‌ای Colab** هستند، نه بنچمارک کالل ۳۰ عکس و نه اثبات قبولی گیت کیفیت. نسخهٔ مخزن و نسخهٔ حرفه‌ای Colab جداگانه نگهداری می‌شوند؛ بنابراین این اجرا مدرک feasibility است، نه ادعای GPU-validation بایت‌به‌بایت برای هر revision مخزن. بنچمارک ۳۰ عکس همچنان اجرا نشده است.
